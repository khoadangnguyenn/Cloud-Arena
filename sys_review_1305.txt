4. Tech Stack - pros & cons
 - php (custom mvc): in app/core, controller, models
   + pros: lightweight, stick to spec, ez to host shared
   + cons: must take responsibility 4 auth, csrf, validation all edge cases
 - mysql + pdo: in models, database.php
   + pros: standard, prepared statements
   + cons: manage migration/schema urself
 - .env + load_env.php: in config.php
   + pros: no hardcode secret in repo
   + cons: need deploy procedure
 - tailwind css (cdn): in client layout
   + pros: fast ui, responsive
   + cons: cdn + jit runtime ==> wide CSP, no optimize bundle production
 - font awesome, gg fonts, themify (client): in header
   + pros: icon/typo abundant
   + cons: add 3rd-party request, rely on CDN
 - AOS (homepage) : in header w cond (isHomePage)
   + pros: lightweight animation
   + cons: add dependency + csp
 - GSAP/Typed.js: in Contact
   + pros: impressive UX
   + cons: heavy js, need to control mobile performance
 - SRTDash + Bootstrap + jQuery: in admin panel
   + pros: correct templete w spec, many component
   + cons: old ver, technical debt w time
 - Fetch API + main.js: in admin autosave, noti, ticket AJAX
   + pros: modern, no axios nedded
   + cons: long logic in 1 file, hard to detach modules
 - Apache mod_headers + CSP: in .htaccess
   + pros: less XSS/clickjacking/MIME sniff
   + cons: CSP loosen w unsafe-inline/eval since CKEditor/CDN
